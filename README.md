# Tenengroup × Deel | Interactive proposal

An independent, single-file website. All images are embedded inside `index.html`, so no `assets/` folder is required.

## Publish with GitHub Pages

1. Open your GitHub repository.
2. Upload **index.html** to the repository root (you can also upload this README).
3. Commit the files to your default branch (usually `main`).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main`, folder `/ (root)`, then **Save**.
7. GitHub will show the published website URL on the Pages settings screen, commonly `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

> GitHub's website does not automatically unpack a ZIP uploaded as one file. Extract the ZIP, then upload its contents to the repository root.
